# Tele-Sena

Projeto acadêmico desenvolvido em Java para simular a venda de
Tele-Senas, geração de números, realização de sorteios,
identificação de ganhadores e distribuição de prêmios.

## Sobre o desenvolvimento

Este projeto foi desenvolvido como atividade acadêmica com auxílio
de Inteligência Artificial na elaboração do código.

O projeto foi utilizado para estudar e praticar conceitos de Java,
Programação Orientada a Objetos, arrays, ArrayList, métodos,
construtores e estruturas de repetição.
